# Somatic

A web-based 3D pain visualization and research platform. People can communicate how pain feels, where it occurs, and how it changes over time through customizable brushes, 3D body painting, animated sensations, and a timeline.

See [CLAUDE_MASTER_PROMPT.md](CLAUDE_MASTER_PROMPT.md) for the full product vision, architecture, and phased roadmap.

> Development uses synthetic data only. No real patient data is collected.
